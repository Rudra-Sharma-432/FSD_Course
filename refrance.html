Level 2 Selectors and colours

The tag selector styles every p. An id picks exactly one element, and a class can be reused on many.

One colour, three ways: keyword (yellow), hex (#2EC4B6), rgb(255, 210, 63).

Three places CSS can live: inline (style="..."), internal (a style block in the head, used on this page) and external (a separate style.css linked in the head).

Level 8 The cascade and units

Weakest to strongest: browser default, universal, tag, class, id, inline, !important.
